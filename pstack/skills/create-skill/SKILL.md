# Droid Skill Authoring Bridge

Load the official `skill-creation` skill from droid-evolved using `Skill`. Retain the caller's source inventory, draft, structural validation, test cases, and iterative evaluation gates. Create SKILL.md under the actual `.factory/skills/` scope or owned plugin source, never edit a plugin cache. Native `/create-skill` is an interactive session wizard, not a tool a noninteractive worker can silently approve. If authoring needs a model-backed eval, run real isolated Droid sessions after authentication; do not claim an unexecuted benchmark passed.
